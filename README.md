# 🌡️ Temperature Converter in C

A lightweight, interactive command-line program built in C that converts temperatures between Celsius and Fahrenheit.

---

## 🚀 Features

- **Bidirectional Conversion:** Converts Celsius to Fahrenheit and Fahrenheit to Celsius.
- **Case-Insensitive Input:** Accepts both uppercase (`C`, `F`) and lowercase (`c`, `f`) inputs using `toupper()`.
- **Double-Precision Accuracy:** Uses `double` variables and `9.0 / 5.0` floating-point division to ensure accurate calculations.
- **Input Validation:** Displays an error message if an invalid unit is entered.
